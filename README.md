# customer-churn-prediction
# End-to-End Customer Churn Prediction using Machine Learning

## Project Overview

This project predicts whether a telecom customer is likely to churn using Machine Learning algorithms and data analysis techniques.

Customer churn prediction helps companies identify customers who are likely to leave their services so that businesses can improve customer retention strategies

## Problem Statement

Telecom companies lose a large number of customers every month. The goal of this project is to:

* Predict customer churn
* Analyze customer behavior
* Identify important churn factors
* Improve customer retention strategies

---

## Dataset

Dataset used:

* Telco Customer Churn Dataset

Dataset includes:

* Customer demographics
* Contract details
* Monthly charges
* Internet services
* Payment methods
* Churn status

## Results

* High prediction accuracy achieved
* Random Forest performed better than Logistic Regression
* Customers with month-to-month contracts had higher churn rates
* Higher monthly charges increased churn probability

---

## Business Insights

* Customers with short-term contracts are more likely to churn
* Customers with high monthly charges show higher risk
* Long-term contract customers are more stable
